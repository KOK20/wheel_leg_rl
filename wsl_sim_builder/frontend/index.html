WSL MuJoCo 仿真生成器

Windows 浏览器传入机械结构与控制函数，WSL 端生成 MJCF，也可以直接启动完整 MuJoCo 图形窗口。

机械结构 JSON

支持 body、joint、geom、actuator 的基础描述。名称需要是英文/数字/下划线，便于控制函数引用。

控制函数 Python

函数签名：control(t, qpos, qvel, ctrl, state)。可用 math、np，demo 环境只适合运行你信任的代码。
