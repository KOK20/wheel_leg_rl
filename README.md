# Parallel Wheel-Leg MuJoCo Simulation

这是一个使用指定 STEP 总装直接拆分生成的轮腿机器人 MuJoCo 仿真项目。

模型尺寸来自已脱敏的机械与控制参数：

- 两髋轴间距：`0.088 m`
- 两根短摇臂：`0.0833 m`
- 两根长连杆：`0.160 m`
- 轮半径：`0.0603 m`

## 运行

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python Simulation.py
```

图形仿真使用独立的固定步进物理线程和显示快照，窗口刷新速度不会改变控制周期。
启动日志应显示 `controller=smooth-vmc-v16`。代码修改后需要关闭旧窗口并重新运行，
已启动的 Python 图形进程不会自动热加载新控制器。运行时日志中的 `real_time` 应接近 `1.00x`；
默认使用轻量几何体和 `45 Hz` 显示刷新，以保证界面流畅；使用 `--detailed-meshes`
可切换到高精度 STEP 网格。也可使用 `--render-hz 60` 调整显示刷新率，或使用
`--status-interval 0` 关闭状态日志。图形窗口左上角默认显示控制和机体状态 HUD；如需隐藏可加 --hide-control-hud。
场景前方约 `x=3.7 m` 处布置了运动学测试地形，包含上坡、平台、下坡、带导入坡的小台阶和左右错位台阶；
从默认起点按住 `W` 即可进入地形区。默认相机会向机器人前方看，打开窗口后应能看到远处测试地形。
继续前进到约 `x=10.9 m` 之后是蓝色无缓坡二级平台：一级约 `0.07 m`，
二级约 `0.12 m`。保持 `W` 靠近垂直前缘或侧边时，控制器会进入低速贴边爬升状态；
也可以手动按 `Space` 测试跳跃通过二级抬升地形。

无图形快速验证：

```bash
.venv/bin/python Simulation.py --headless --seconds 5
.venv/bin/python -m pytest -q
```

## 控制

- 按住 `W / S` 或 `↑ / ↓`：前进 / 后退，目标速度 `0.50 m/s`，松开后停止
- 按住 `A / D` 或 `← / →`：左转 / 右转，松开后停止旋转
- `PageUp / PageDown`：伸长 / 缩短虚拟腿
- `[ / ]`：虚拟腿前后摆动
- `Space`：跳跃动作
- `X`：停止轮速和转向
- `R`：一键复位，清空当前仿真/控制/键盘状态并回到初始姿态

方向键或 `W/A/S/D` 使用按住生效、松开归零的瞬时控制逻辑，按 `X` 可立即停止。空格触发一次完整的
压腿、爆发伸腿、空中收腿和落地恢复流程。机器人翻倒、卡死或进入无法自救状态时，可按 `R`
回到初始位置与默认腿部装配姿态。

交互与控制器把腿长限制在 `0.105-0.205 m`、虚拟腿摆角限制在 `±0.35 rad`
（约 `±20°`）。MJCF 腿部髋/膝关节还设置了对应工作包络的机械硬限位，轮轴保持连续旋转。
五连杆逆解使用 `l1/l4` 分别位于前后髋轴外侧的外展装配分支，并在动态限位中保留外展余量。
当前机械闭环使用导出模型中的四组连接约束。

## VMC + LQR 控制

已脱敏的嵌入式控制结构用于参数参考：

- 五连杆正运动学与实时雅可比
- VMC 将虚拟轴向支撑力 `F0` 和虚拟腿摆矩 `Tp` 映射为双髋关节力矩
- 六状态 LQR 控制虚拟腿角、位置、速度、车体俯仰和俯仰角速度；轮矩负责纵向运动，虚拟腿 `Tp` 直接参与机体俯仰平衡
- 腿长 PD、重力前馈、横滚支撑力差和偏航差速控制
- 偏航速率 PI 控制补偿 MuJoCo 圆柱接触缺少轮胎各向异性摩擦导致的转向阻力
- 控制周期提升到 `1 kHz`，解析五连杆 Jacobian 替代数值差分
- 初始化时直接清零真实腿长速度，避免非默认腿长启动时产生错误阻尼冲击
- 腿部只使用力矩执行器，通过虚拟弹簧/阻尼力柔顺支撑机身，不使用腿长位置执行器
- 速度和转向命令使用斜坡限制，转向期间采用航向角速度模式，并保留轮矩与虚拟腿力矩的平衡裕量
- 停止和前后换向会重置纵向行程目标；零速附近释放残余位置误差并提高速度阻尼，避免频繁操作后继续追旧目标
- 纵向位置回拉经过柔化，持续前进/后退时优先跟踪速度，减少启停时的顿挫
- 键盘前后移动目标速度提高到 `0.50 m/s`，仍使用平滑速度斜坡进入目标速度
- 前后起步和换向使用更柔和的目标速度斜坡，并提高虚拟腿 `Tp` 的腿角阻尼，抑制轮腿摆动震荡
- 快速前进脉冲进一步降低目标加速度、髋关节力矩变化率和腿速估计带宽，减少启停时腿部抽动
- `A/D` 转向目标提高到 `0.75 rad/s`，并加入小幅差速轮矩与更快的偏航辅助响应
- 左右旋转停止或换向时立即清空旧偏航速率目标，避免松开/停止后继续滑转
- 纵向平衡使用左右虚拟腿平均状态，转向时使用更强的腿角同步阻尼和横滚补偿处理左右差异，避免两侧腿相对摆动被放大
- 腿长虚拟弹簧采用较低带宽以改善减震；低腿长时自动柔化轮矩、髋摆矩和腿长弹簧，减少低位抖动；双轮离地后释放轮矩，仅保留虚拟腿姿态控制
- 零指令下若机体长时间大俯仰，进入 `tip recovery`：持续清空行程误差，轮矩限制到低扭矩扶正范围，同时伸腿并加强虚拟腿摆矩，避免满轮矩疯车或原地趴住
- 低速或原地转向时若出现大俯仰满轮矩，进入 `stall pose`：清空行程误差、禁用偏航辅助，并按输入方向选择恢复轮矩；前进卡边会低扭矩后退，后退脱困会强制负轮矩，纯转向则取消轮驱
- 着地检测同时识别平地和 `terrain_*` 测试地形，轮子在坡道或台阶上接触时不会被误判为离地
- 前进中跳跃会临时冻结前进/转向目标并在落地后短暂恢复；高速移动跳跃会降低爆发力，普通测试地形上按住前进时会抑制完整弹跳，避免台阶落地翻车
- 所有可爬升抬高盒体附近不再基于距离自动起跳；按住前进靠近正面、侧面或背面边缘时，会低速伸腿贴边爬升，并加入小幅上托/贴附虚拟力，限制轮矩和偏航辅助，尽量模拟“贴上去再爬”的动作
- 跳跃平台前缘带堵转保护：持续顶住垂直边缘时会自动收腿，短暂释放位置误差并施加小幅脱困力；若继续按前进，会停止继续硬顶，反向或跳跃可立即解除锁定
- 机身带透明碰撞壳，测试地形台阶也带坡化前缘；机器人翻倒时机身会与地面/地形发生接触，不会穿过地图继续下沉
- 二级平台使用无导入坡的 `terrain_jump_*` 垂直支撑面，仍参与着地检测；平台接触面提高摩擦，并在前缘加入小圆角接触唇边，便于测试贴边上台阶和手动跳跃两种通过方式

单侧前关节电机连接车体前侧支链，后关节电机连接后侧支链；MJCF 中前髋位于
`-X`、后髋位于 `+X`。前后关节身份、执行器通道和 VMC 力矩映射保持一致。

机身已释放升降、横滚和俯仰自由度。仿真 LQR 增益按当前 STEP 模型质量和 MuJoCo
接触参数调节，没有直接照搬嵌入式模型的增益数值。

## 控制 HUD

图形 HUD 仅显示当前仿真的控制和机体信息，便于调参和观察状态：

- 控制数据：速度/偏航指令、滤波后的目标速度/偏航、行程目标、腿长/摆角目标
- 执行器数据：左右轮力矩、左右前后髋关节力矩、偏航辅助力矩
- 机体数据：位置、横滚/俯仰/偏航姿态、接触地形、离地时间、跳跃状态
- 腿部数据：左右腿长、腿角和腿长速度
